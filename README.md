# NoCap Games

**70 free games for everyone. No download, no sign-up. Pick one and play!**

▶ **Play now: https://poojagohel.github.io/nocap-games/**

Quick games for a spare minute: arcade classics, puzzles, brain teasers, games against a bot, and games to play with a friend on the same device.

## Playing

- **Pick a game** from the home page. Filter by category, search, or tap 🎲 **Surprise me**.
- **While playing**, the game list stays on the left so you can jump to another game, and there are **Full screen** and **Next** buttons above the game.
- **Keyboard:** most games use the arrow keys and <kbd>space</kbd>. Each game's rules list its keys.
- **Phone or tablet:** tap the screen or use the buttons under it. On a small screen, tapping a game opens it full size.
- **New games** have a 🆕 NEW tag. Tap ✨ **New** on the home page to see only those.
- **Restart** any game with the ↺ Restart button.
- **Share a game:** open it, then copy the address from your browser. It ends with the game, like `#snake`, so the link opens that game straight away.

## For developers

The website's game list is a small React app (built with [Vite](https://vitejs.dev)). Each game is its own page in `public/games/` and runs in a frame next to the list.

### Run and build

You need [Node.js](https://nodejs.org) 18 or newer.

```
npm install
npm run dev        # local dev server
npm run build      # makes dist/
npm run preview    # serves dist/ to check the build
```

### Publish

**Live site:** https://poojagohel.github.io/nocap-games/

To update the live site on GitHub Pages:

```
npm run deploy
```

This builds the site and pushes `dist/` to the `gh-pages` branch, which GitHub Pages serves. The update shows up within a minute or two. Commit and push your code to `main` as usual; `npm run deploy` only publishes the built site.

To host it somewhere else instead, run `npm run build`, then **upload everything inside `dist/`** to any static host (Netlify, Vercel, GitHub Pages, cPanel, S3...). Paths are relative, so the site also works from a subfolder. No server code is needed.

### Project layout

| Path | What it is |
|---|---|
| `index.html`, `src/main.jsx` | Entry point of the React app |
| `src/App.jsx` | The game list, search, and the game area |
| `src/games.js` | The list of games shown on the site (name, folder, short description) |
| `src/styles.css` | The look of the main page |
| `public/games/<name>/` | One folder per game, copied into the build as-is |

Every game folder has the same files, and each one also works on its own (open its `index.html`):

| File | What it does |
|---|---|
| `index.html` | The game page: screen, phone buttons and rules |
| `style.css` | The look of the game page |
| `engine.js` | Shared mini game engine (screen, drawing, input, game loop). Identical in every folder |
| `game.js` | The game itself. Edit this to change the game |
| `README.md` | Rules and an engine cheat sheet |

### Add a game

1. Copy a game folder in `public/games/` (pick one that plays a bit like your new game) and give it a new name.
2. Write your game in its `game.js`, and update the title and rules in its `index.html`.
3. Add a line for it in the right category in `src/games.js`.
4. Run `npm run dev` to try it, then `npm run build`.

### How games look

The shared `engine.js` styles every game automatically, so a new game looks like the rest with no extra work:

- `wipe(color)` adds lighting to the background: dark colors get glowing light and twinkling stars, light colors (like a sky) get drifting clouds of light, and colors in between get soft light from above.
- `box(...)` has slightly rounded corners and a thin light top edge. For boxes that touch each other (a tile board), set `Engine.round = 0` while drawing them.
- `bubble(...)` is shaded like a ball. Very dark circles are shaded like holes.
- Light text gets a soft shadow.
