Color Clash

Decide if the word's COLOR matches what the word SAYS. RED in red = match. RED in blue = no match.

Keyboard works anywhere on the page. On a phone, tap the screen or use the buttons.

How to play

Goal
Decide if the word's COLOR matches what the word SAYS. RED in red = match. RED in blue = no match.
Controls
Tap ✅ match or ❌ no match. Keys: ← or Y = match, → or N = no match.
Speed
You start with 3 seconds per word, and it gets faster as your score climbs.
Lose
A wrong answer or running out of time costs a ❤️. You have 3 hearts.
Why
Your brain reads the word before it sees the color. This is a famous brain test called the Stroop effect.
