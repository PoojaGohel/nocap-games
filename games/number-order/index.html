Number Order

Remember where each number is, then tap 1, 2, 3... in order.

Keyboard works anywhere on the page. On a phone, tap the screen or use the buttons.

How to play

Goal
Remember where each number is, then tap 1, 2, 3... in order.
Twist
The moment you tap 1, all the other numbers turn into blank squares.
Levels
Level 1 has 3 numbers. Every level adds one more.
Lose
A wrong tap costs a ❤️ and shows you the answers. You have 3 hearts.
