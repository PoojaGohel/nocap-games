Path Recall

Watch the 🐸 hop from square to square, then tap the squares in the same order.

Keyboard works anywhere on the page. On a phone, tap the screen or use the buttons.

How to play

Goal
Watch the 🐸 hop from square to square, then tap the squares in the same order.
Backwards
Every 3rd level, you must tap the path in REVERSE order, starting from the last square 🔄.
Levels
Each level the path is one hop longer. From level 6 the grid grows to 5×5.
Lose
A wrong tap costs a ❤️ and shows the real path with numbers. You have 3 hearts.
