Simon

Repeat the color pattern for as long as you can.

Keyboard works anywhere on the page. On a phone, tap the screen or use the buttons.

How to play

Goal
Repeat the color pattern for as long as you can.
How
Watch the pads flash, then repeat them in the same order.
Keys
↑ ← → ↓ match where the pads are.
Phone
Tap the pads.
Lose
One wrong pad ends the game. Each round adds one more step.
