Stack

Build the tallest tower you can.

Keyboard works anywhere on the page. On a phone, tap the screen or use the buttons.

How to play

Goal
Build the tallest tower you can.
Keys
space to drop the sliding block.
Phone
Tap the screen.
How
Only the part that lands on the tower stays, so blocks get smaller. Each block slides a bit faster.
Lose
Miss the tower completely.
