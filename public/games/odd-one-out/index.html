Odd One Out

All the emojis are the same except one. Find it and tap it before the timer runs out.

Keyboard works anywhere on the page. On a phone, tap the screen or use the buttons.

How to play

Goal
All the emojis are the same except one. Find it and tap it before the timer runs out.
Levels
Every find = level up. The grid gets bigger, and from level 4 the difference is sneaky (😀 vs 😃).
Lose
Tapping the wrong one or running out of time costs a ❤️. The odd one gets circled so you can see it.
